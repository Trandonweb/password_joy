# ... # 주석 영역은 현재 언어의 규칙으로 계속 변환합니다.
\ ... \ 익스케이프 영역은 반대 언어의 문자열로 취급합니다. 암호화 결과에는 경계 표시를 유지하고, 복호화 결과에서는 내부 문자열만 남깁니다.
예: JOY 입력의 \....\는 a가 아니라 문자 ....로 처리됩니다.
한글 음절 경계는 ;로 구분하며, 문자 토큰 사이의 /와는 다릅니다.
JOY3는 문자 인코딩 방식이며, 실제 보안용 암호화 알고리즘은 아닙니다.
